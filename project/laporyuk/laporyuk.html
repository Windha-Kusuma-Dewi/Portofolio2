LaporYuk

In Progress

Description

LaporYuk is a UI/UX design concept for a school facility complaint and reporting web app, built for a single school (not a multi-tenant system). It lets students and staff report issues with school facilities and lets admins track and manage those reports.

Highlights

  • Designed the complete user flow in Figma, from public landing page and authentication to reporter dashboard and report submission form
  • Built a 4-stage status tracking system (submitted, verified, in progress, completed) to keep reporters informed
  • Created modal interactions for key confirmations, including logout, password change, and account deletion
  • Applied a consistent navy/blue color palette across all screens, using Auto Layout for clean spacing
